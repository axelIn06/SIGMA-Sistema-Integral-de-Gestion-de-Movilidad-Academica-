# Módulos

## Compartidos

Autenticación, usuarios y roles, convocatorias, requisitos, documentos versionados, observaciones, notificaciones, cartas, auditoría y reportes.

## SGMS

Perfil UNSAAC, convocatoria, postulación, destino, documentos, evaluación OCRI, ranking, cartas y seguimiento.

Estados: `BORRADOR`, `POSTULADO`, `EN_REVISION_DOCUMENTAL`, `OBSERVADO`, `SUBSANADO`, `APROBADO_OCRI`, `ENVIADO_A_UNIVERSIDAD_DESTINO`, `ACEPTADO`, `RECHAZADO`, `FINALIZADO`.

## SGME

Universidad de origen, nominación, perfil externo, actividad/cursos, revisión OCRI, validación académica, carta de aceptación y llegada.

Estados: `NOMINADO`, `REGISTRO_PENDIENTE`, `POSTULACION_ENVIADA`, `EN_REVISION_OCRI`, `OBSERVADO`, `VALIDACION_ACADEMICA`, `APROBADO`, `CARTA_ACEPTACION_EMITIDA`, `CONFIRMADO`, `EN_MOVILIDAD`, `FINALIZADO`.
