# Flujo SGMS

1. El alumno accede con identidad institucional y completa su perfil.
2. Selecciona una convocatoria activa y guarda un borrador.
3. El sistema crea el checklist requerido.
4. El alumno carga versiones PDF y envía la postulación.
5. OCRI aprueba u observa cada documento.
6. El alumno subsana sin perder versiones anteriores.
7. OCRI evalúa el expediente y registra su decisión.
8. Se generan oficios/cartas y se registra la respuesta del destino.
9. El expediente llega a aceptado, rechazado o finalizado.
