# Roles y permisos

| Rol | Alcance |
| --- | --- |
| Alumno UNSAAC | Su perfil, convocatorias salientes y sus expedientes |
| Estudiante externo | Su nominación y expedientes entrantes |
| Universidad de origen | Nominaciones de su institución |
| Evaluador OCRI | Lectura de expedientes y revisión documental |
| Administrador OCRI | Convocatorias, requisitos, usuarios, decisiones y reportes |
| Coordinador/Facultad | Validación académica asignada |
| Superadmin | Configuración y administración técnica |

Toda autorización debe comprobarse en el servidor. Las URLs de archivos serán firmadas y temporales. Las acciones sensibles producirán un registro de auditoría.
